## 출처와 고른 기준 (2026-11-13)
- 한국관광공사 TourAPI 제주 자료 1,789곳 (ktriptips.com 미러에서 수집). 좌표·주소·운영시간·휴무·요금·사진은 그 자료 그대로예요.
- 사진은 모두 관광공사 사진이에요. 공공누리 1유형 349장(출처 표시), 3유형 651장(출처 표시 + 변경 금지). `image_source` 와 `place_sources.csv` 에 적혀 있어요.
- 면세점·사후면세점 374곳 제외. 기존 `data/seed` 74곳과 같거나 100m 안인 82곳 제외.
- 서로 100m 안인 장소 192곳은 하나로 합치고, 남긴 장소의 `description_en` 끝에 "Nearby:" 로 적었어요.
- `name_en`: 관광공사 영어 자료에 있으면 그 이름(115곳), 없으면 로마자 표기·번역. `description_en`, `opening_hours`, `closed_days`, `signature_menu_en` 은 관광공사 한국어 자료를 번역한 값이에요.

## 쓰기 전에 알아둘 점
- **지도 범위:** 992곳 중 84곳만 main 의 지도 범위(제주시 시내) 안이에요. `backend/app/data/places.json` 은 범위를 제주 본섬 전체(위도 33.10~33.58, 경도 126.13~126.99)로 넓혀서 만든 결과예요. 코드의 범위는 아직 안 바뀌었으니 `backend/scripts/build_places.py` 의 `BOUNDS`, `frontend/config/map.ts` 의 `bounds`, 대체 SVG 지도를 함께 넓혀야 해요.
- **가격:** 식당·카페는 관광공사 자료에 메뉴 가격이 없어 `price_level` 이 빈칸이에요. 관광지는 자료에 요금이 적힌 곳만 채웠어요.
- **빈칸:** `avg_stay_min`, `walking_level`, `fatigue_score`, 계단·휠체어 정보는 조사하지 않았어요. `build_places.py` 는 빈칸을 기본값(45분, 1, 1)으로 채워요.
- **확인 수준:** 한 곳씩 직접 확인한 값이 아니라 관광공사 자료를 그대로 옮긴 값이에요. `last_verified_at` 은 자료를 가져온 날짜(2026-11-13)예요.
- **송악산 진지동굴(id 198):** 관광공사 소개글에 붕괴 위험으로 출입 금지라고 적혀 있어요.
