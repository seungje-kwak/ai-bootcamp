    ⑦ 헷갈리는 말 정리
    
  
    위에 나온 용어를 한 번에 모았어요.
    
  
    
    
    🏠 127.0.0.1 = localhost
      
    "지금 이 컴퓨터 자기 자신"이라는 특별한 주소예요. 내 컴퓨터의 인터넷 IP가 아니라서, 다른 사람이 이 주소를 치면 그 사람 컴퓨터를 가리켜요. 그래서 로컬 테스트에만 써요.
    
    
    🚪 포트 :8000, :5173, $PORT
      
    한 건물(컴퓨터) 안의 "몇 번 문"이에요. 로컬에선 내가 8000번을 정했고, Railway에선 Railway가 정해 준 번호($PORT)를 써요.
    
    
    📮 HTTP · GET / POST / DELETE
      
    컴퓨터끼리 주고받는 편지 형식이에요. GET = 보여줘, POST = 넣어줘, DELETE = 지워줘. /notes는 받는 사람(메뉴) 칸이에요.
    
    
    🔢 상태 번호 200 · 201 · 204 · 404 · 422
      
    답장 맨 위에 붙는 결과 번호예요. 200번대 = 성공, 404 = 그런 주소/데이터 없음, 422 = 주문서 양식이 틀림, 500번대 = 서버 쪽 문제.
    
    
    🧭 라우터 · @app.get(...)
      
    함수 위에 붙인 @ 표시(데코레이터)가 "이 주소로 오면 이 함수를 불러줘"라고 FastAPI 메뉴판에 적어 두는 역할이에요.
    
    
    📝 Pydantic · NoteIn
      
    주문서 양식이에요. "content는 1~500자 글자"처럼 규칙을 적어 두면, 어긋난 주문은 내 함수에 닿기 전에 FastAPI가 422로 돌려보내요.
    
    
    🔑 .env · 환경변수
      
    프로그램 바깥에 적어 두는 설정값이에요. 로컬에선 .env 파일, Railway에선 Variables 칸에 적고, main.py는 os.environ[...]로 똑같이 꺼내 써요.
    
    
    📦 컨테이너
      
    내 코드 + 파이썬 + 설치한 라이브러리를 한 상자에 담은 것이에요. Railway는 이 상자를 자기 컴퓨터에서 켜 둬요.
