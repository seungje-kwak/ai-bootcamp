# AI 부트캠프 웹페이지

HTML, CSS, JavaScript만으로 동작하는 연습용 웹페이지입니다. 서버나 데이터베이스 없이 HTML 파일을 브라우저에서 열면 실행됩니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `hello.html` | 인사와 오늘의 목표를 담은 한 파일짜리 페이지 |
| `index.html` | 명언 페이지의 구조 |
| `quotes.css` | 명언 페이지의 카드 디자인과 반응형 레이아웃 |
| `quotes.js` | 명언 데이터, 무작위 변경, 복사 기능 |

## 실행 방법

1. 보고 싶은 HTML 파일을 더블클릭하거나, 브라우저로 끌어다 놓습니다.
2. `index.html`은 같은 폴더의 `quotes.css`, `quotes.js`를 함께 읽습니다. 세 파일을 같은 위치에 두세요.

## 인사 페이지 (`hello.html`)

- 이름을 입력하고 **인사하기**를 누르면 `반갑습니다, ○○님!`이 표시됩니다. 이름이 비어 있으면 입력을 요청합니다.
- **오늘의 목표**를 입력하고 **저장하기**를 누르면 브라우저 로컬스토리지에 저장됩니다.
- 저장 키는 `todayGoal-2026-11-06`처럼 날짜가 붙어 있습니다. 페이지를 다시 열어도 오늘 목표는 남고, 다음 날에는 새 목표를 적습니다.
- 목표를 비우거나 공백만 입력하면 저장되지 않습니다.

## 명언 페이지 (`index.html`)

- 제목, 명언, 작성자, **새로운 명언 보기**, **명언 복사하기**로 구성됩니다.
- 명언은 `quotes.js`의 배열로 관리됩니다. 페이지를 열면 무작위로 한 문장이 나오고, 버튼을 누를 때마다 직전과 다른 명언으로 바뀝니다.
- 명언이 바뀔 때 글자가 잠깐 사라졌다가 나타나는 애니메이션이 적용됩니다.
- **명언 복사하기**는 `“명언” — 작성자` 형태로 클립보드에 복사하고, 잠시 `명언을 복사했습니다.`를 보여 줍니다.
- 화면이 좁으면 버튼이 세로로 쌓입니다.

## 명언 수정

`quotes.js` 맨 위 `quotes` 배열에 한 줄을 추가합니다.

```javascript
{ text: "새 명언 문장", author: "작성자" },
```

저장한 뒤 브라우저에서 `index.html`을 새로고침하면 새 문장이 무작위 목록에 포함됩니다.
